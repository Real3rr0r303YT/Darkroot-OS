Darkroot OS is a Gentoo-based Linux distribution with its own runit init, a graphical Calamares installer and two fully debloated desktops, plus a Hacker Mode for security work.

Choose your edition

One ISO. Three moods.

Pick your desktop in the installer. Everything else stays the same rock-solid Gentoo base.

DARKROOT SHELL

Hyprland, Apple-style

Tiling Wayland with a glassy menu bar, a centered dock, blur and rounded corners. Hyprland keybinds, zero bloat.

GNOME MINIMAL

GNOME, debloated

Just the shell, Files, Console and Settings. No games, no web apps and no tracker, so it stays fast and quiet.

HACKER MODE

Security toolkit

Get it

Download Darkroot OS

One live ISO for UEFI and BIOS. Boot it, try the Darkroot Shell, then click Install Darkroot in the dock.

Download v2026.11 (3.2 GB)
The ISO is split into two parts (GitHub allows max. 2 GB per file). Download part-00, part-01 and the .sha256 file, then join them (Linux/macOS, then Windows):
cat darkroot-2026.11-x86_64.iso.part-* > darkroot-2026.11-x86_64.iso copy /b darkroot-2026.11-x86_64.iso.part-00 + darkroot-2026.11-x86_64.iso.part-01 darkroot-2026.11-x86_64.iso
SHA256: 8c831b8d292ff0c08f1cf694deb46b9d261824af211be21aa4acaa90543dbc87
1. Flash it with Ventoy, balenaEtcher or dd.
2. Boot from USB and try the live desktop.
3. Click Install Darkroot, pick an edition and optionally Hacker Mode.
sudo dd if=darkroot-2026.11-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync
